# pulsr

it makes the squiggly mountain lines out of whatever your computer is playing. in your terminal. thats the whole thing.

written in rust. macos (apple silicon, 14.2+) and linux (pulseaudio or pipewire).

## get it

```sh
brew install 1337raspberry/tap/pulsr
```

or grab a build from releases. or `cargo build --release` if you are like that.

## use it

```sh
pulsr
```

play some music. `q` to quit. `pulsr -help` for the rest, there are themes and stuff.

on macos it asks for audio capture permission the first time. say yes or enjoy a flat line.
